UNDER THE HOOD

Same math. Different
work distribution.

Each run multiplies two seeded square matrices using the same JavaScript kernel. The parallel path splits independent output rows across Web Workers; the sequential path assigns all rows to one worker.

01 / SPEEDUP
Tsequential ÷ Tparallel

Above 1× means the parallel run finished sooner. Below 1× means worker coordination outweighed the work saved.

02 / EFFICIENCY
Speedup ÷ workers

Shows the speedup per worker. Values above 100% can occur from timing noise or workload effects; repeat the run to compare.

03 / READ THE RESULT
A browser measurement

Warm worker pools are reused across rounds; startup and input-copy time is shown separately. Results depend on your CPU, browser, background activity, and thermal state. This is an educational comparison, not a hardware benchmark.
